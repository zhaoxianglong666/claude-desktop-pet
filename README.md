# 小克 · Claude 桌宠

一只住在 Claude 桌面版输入框上的像素小螃蟹。照着 Claude Code 终端里的吉祥物一格一格画出来：网格、比例、颜色（`#D77757`）都和终端里一样，默认就是吉祥物原大（约 40×25 像素）。

> 这是粉丝做的非官方小项目，和 Anthropic 没有关系。Claude 及其吉祥物形象归 Anthropic 所有。

## 它会做什么

小克站在 Claude 窗口**输入框的麦克风图标上面**，挪动或缩放 Claude 窗口它都会跟着走。它只浮在 Claude 上面，切到别的程序不会挡着你，Claude 最小化它也跟着藏起来。

| 你在做什么 | 小克在做什么 |
|---|---|
| 打开 Claude | 从输入框里蹦出来打招呼 |
| 在 Claude 里用 **Code** | 敲代码（笔记本 + 迷你终端） |
| 在 Claude 里用 **Chat** | 看书、翻页 |
| 在 Claude 里**开始打字** | 蹦一下跟你打招呼（睡着的话会被叫醒） |
| 关掉 Claude | 说声“下班咯”，跳回输入框消失 |
| 其他时候 | 大部分时间在睡觉，每隔 3～7 分钟起来活动一下 |

另外：在 Code/Chat 里 5 分钟没动键盘鼠标它会打盹；连续工作 50 分钟会提醒你休息。

## 要求

- Windows 10 / 11
- [Claude 桌面版](https://claude.ai/download)
- Python 3.8+（安装时勾选 tkinter，官方安装包默认就有）

只用到 Python 自带的库（tkinter + ctypes）和 Windows 自带的 PowerShell，不需要 `pip install` 任何东西。

## 安装和使用

```bash
git clone <这个仓库的地址>
```

- **双击 `启动桌宠.vbs`**：小克马上出现。
- **右键小克**：手动选动作（敲代码 / 翻书 / 思考 / 散步 / 伸懒腰 / 睡觉 / 发呆）、调大小、开关“跟着 Claude 自动出现（开机自启）”、躲起来、退出。
- **左键点它**：蹦一下、冒爱心、说句话。**按住拖动**可以换个位置站，右键“回到麦克风上面”可以让它回去。

勾上“跟着 Claude 自动出现”后，小克会在开机时悄悄启动，等你打开 Claude 才出来。

## 自定义

第一次运行会生成 `config.json`，可以改：

- `pixel`：大小（每个像素格的宽度，2.5 = 吉祥物原大）
- `sleep_after_min`：几分钟不动就打盹
- `break_remind_min`：几分钟提醒休息

改完右键退出再启动。

## 它是怎么知道你在干什么的

- `claude_probe.ps1` 用 Windows 自带的 UI Automation 读取 Claude 窗口当前页面的**地址**（`claude.ai/chat/…` 是 Chat，`claude.ai/epitaxy/…` 是 Code）以及输入框和麦克风按钮的**位置**，不读任何对话内容。
- “你开始打字”只检测有没有按键被按下，不记录按了什么。
- 运行日志写在 `pet.log`，只记录页面地址和模式切换，方便排查。

## 文件

| 文件 | 作用 |
|---|---|
| `pet.pyw` | 主程序 |
| `claude_probe.ps1` | 读取 Claude 窗口页面地址和输入框位置 |
| `启动桌宠.vbs` | 双击启动（不弹黑窗口） |
